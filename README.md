# После 9-го

Чат-бот и мини-приложение в MAX, которые помогают семье девятиклассника спланировать год и выбрать путь: 10 класс или колледж.

> Проект в разработке. Сейчас готовы доменная логика, справочные данные (демо), API и бот. Мини-приложение, Docker и полная документация — следующие этапы, см. [план разработки](docs/development-plan.md).

## Быстрый старт для разработки

Нужен Node.js 24 или новее.

```bash
npm install
cp .env.example .env
npm test
npm run dev:server
```

Без токена бота сервер можно запустить в режиме локальной разработки: в `.env` укажите `BOT_ENABLED=false` и `AUTH_DEV_BYPASS=true`, а в запросах к API передавайте заголовок `X-Dev-User-Id`.

## Структура

| Папка | Что внутри |
|---|---|
| `packages/core` | доменная логика: средний балл аттестата, построение плана, расписание напоминаний |
| `apps/server` | HTTP API мини-приложения, чат-бот MAX, планировщик напоминаний, SQLite |
| `apps/miniapp` | мини-приложение на React и MAX UI |
| `data` | справочники: регионы, колледжи, специальности, ключевые даты, тексты |
| `docs` | план разработки и документация |

Все данные в папке `data` сейчас демонстрационные — подробнее в [data/README.md](data/README.md).
