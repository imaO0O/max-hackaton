# Презентация

- `index.html` — исходник: 13 слайдов 16:9, стили внутри файла. Первый слайд — техническая информация для проверки (организаторы его не оценивают), второй — команда и роли.
- `presentation.pdf` — черновик для сдачи, напечатан из `index.html`.
- `screens/` — скриншоты мини-приложения: локальный запуск со всеми ветками этапов 2–5, телефон 390×844, пилотный регион Татарстан.

## Перед сдачей

1. Заполнить места, выделенные жёлтым:
   - слайд 1 — хэш коммита, который сдаётся: `git rev-parse HEAD` в `main`;
   - слайд 2 — название или номер команды, трек хакатона, имена участников А и Б;
   - слайды 3 и 7 — цифры и цитата из интервью (`docs/interview-guide.md`, таблица итогов).
2. Заменить скриншоты в `screens/` снимками из MAX после деплоя — с теми же именами файлов.
3. Проверить цифры на слайдах 2 и 8: число автотестов — по выводу `npm test`. Если сменится адрес сервера, обновить его на слайдах 1 и 9, в `DATA-API.yaml` и в `docs/openapi.yaml`.
4. Напечатать PDF заново.

## Как напечатать PDF

Открыть `index.html` в Chrome или Edge → «Печать» → «Сохранить как PDF». Размер страницы задан в файле; в настройках: поля — «Нет», «Фоновая графика» — включить, колонтитулы — выключить. Сохранить поверх `presentation.pdf`.
