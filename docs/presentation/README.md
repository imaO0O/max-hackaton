# Презентация

- `index.html` — исходник: 12 слайдов 16:9, стили внутри файла.
- `presentation.pdf` — черновик для сдачи, напечатан из `index.html`.
- `screens/` — скриншоты мини-приложения: локальный запуск со всеми ветками этапов 2–5, телефон 390×844, пилотный регион Татарстан.

## Перед сдачей

1. Заполнить места, выделенные жёлтым:
   - слайд 1 — ссылка на бота после модерации и хэш коммита, который сдаётся (`git rev-parse HEAD` в `main`);
   - слайды 2 и 6 — цифры и цитата из интервью (`docs/interview-guide.md`, таблица итогов).
2. Заменить скриншоты в `screens/` снимками из MAX после деплоя — с теми же именами файлов.
3. Проверить цифры на слайде 7: число автотестов — по выводу `npm test`.
4. Напечатать PDF заново.

## Как напечатать PDF

Открыть `index.html` в Chrome или Edge → «Печать» → «Сохранить как PDF». Размер страницы задан в файле; в настройках: поля — «Нет», «Фоновая графика» — включить, колонтитулы — выключить. Сохранить поверх `presentation.pdf`.
