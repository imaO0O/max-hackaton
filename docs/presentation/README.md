# Презентация

- `index.html` — исходник: 17 слайдов 16:9, стили внутри файла. Первый слайд — техническая информация для проверки (организаторы его не оценивают), второй — команда и резюме проекта. Порядок следует рекомендациям кейса: аудитория и проблема, As Is → To Be, решение, механики, возможности MAX, эффект, границы MVP, архитектура, данные, масштабирование (два слайда), риски и допущения, пилот, источники. Материал для слайдов — `docs/research.md`.
- `presentation.pdf` — черновик для сдачи, напечатан из `index.html`.
- `screens/` — скриншоты мини-приложения: локальный запуск со всеми ветками этапов 2–5, телефон 390×844, пилотный регион Татарстан.

## Перед сдачей

1. Заполнить места, выделенные жёлтым:
   - слайд 1 — хэш коммита, который сдаётся: `git rev-parse HEAD` в `main`; значение `BOT_TOKEN` — только в версии PDF для личного кабинета, в репозиторий токен не попадает;
   - слайд 2 — название или номер команды, имена и зоны ответственности трёх участников.

   Опрос родителей команда не проводит: на слайдах 3, 9 и 15 это прямо сказано, гипотезы проверяются данными продукта в пилоте.
2. Заменить скриншоты в `screens/` снимками из MAX после деплоя — с теми же именами файлов.
3. Проверить число автотестов на слайдах 2 и 11 — сумма по выводу `npm test` (ядро + сервер). Если сменится адрес сервера, обновить его на слайдах 1 и 9, в `DATA-API.yaml` и в `docs/openapi.yaml`.
4. Напечатать PDF заново.

## Как напечатать PDF

Открыть `index.html` в Chrome или Edge → «Печать» → «Сохранить как PDF». Размер страницы задан в файле; в настройках: поля — «Нет», «Фоновая графика» — включить, колонтитулы — выключить. Сохранить поверх `presentation.pdf`.
