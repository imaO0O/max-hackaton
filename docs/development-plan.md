# План разработки «После 9-го» на двух участников

Участники условно обозначены **А** и **Б**. Распределите роли по опыту: А ведёт серверную часть и инфраструктуру, Б — мини-приложение и продуктовые материалы. Жирным отмечен ответственный, второй участник помогает и проверяет.

**Дедлайн онлайн-этапа — 30 сентября 2026, 12:00 МСК**, сдача в личном кабинете. Заморозка — 29 сентября вечером. Финал — 29 октября, Казань.

Ответы организаторов, которые влияют на план: бота выдают организаторы (есть только токен, без административного доступа, ник на онлайн-этапе не меняется); мини-приложение привязывают они же по ссылке из формы; бот должен работать весь период проверки; ИИ-инструменты можно использовать только как помощника — решение команда должна понимать сама.

## Роли

| | Участник А — сервер и платформа | Участник Б — мини-приложение и продукт |
|---|---|---|
| Код | API, бот, напоминания, база, тесты | экраны мини-приложения, MAX UI, MAX Bridge, состояния загрузки и ошибок |
| Инфраструктура | Docker, хостинг с HTTPS, ссылка на мини-приложение в форме организаторов | проверка сценария в мобильной и веб-версии MAX |
| Данные | формат данных, проверка `npm run data:check` | сбор колледжей пилотного региона, сверка дат с первоисточниками |
| Материалы | техническая часть README, архитектура, первый слайд презентации | интервью, продуктовая часть презентации, скриншоты и демо |

## Правила работы с git

- `main` всегда рабочий: тесты проходят, сценарий не сломан.
- Задачи — в отдельных ветках `feature/<кратко>`, в `main` через pull request с ревью второго участника.
- Перед пушем: `npm test` и `npm run data:check`.
- Токены, пароли и `.env` не коммитятся. Если секрет попал в историю — перевыпустить токен.
- Сообщения коммитов — по-русски, в повелительном наклонении: «Добавить экран колледжей».

## Риски и что делать

| Риск | Что делать |
|---|---|
| Мини-приложение не открывается в MAX из-за HTTPS или URL | развернуть хостинг на этапе 0, проверить пустую страницу до готовности экранов |
| Метод MAX Bridge не работает в веб-версии | у каждого метода запасной вариант: копирование ссылки, открытие ссылки |
| Реальные проходные баллы не опубликованы | оставить поле пустым, показать «нет данных», источник — сайт колледжа |
| Не успеваем всё | «желательно» и «можно» не делаем, основной сценарий важнее |
