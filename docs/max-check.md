# Проверка в MAX

Чек-лист для этапов 2–3: пройти основной сценарий в мобильном MAX (iOS или Android) и в веб-версии, записать проблемы в журнал внизу. Повторить сценарий 3 раза подряд без сбоев.

## Перед проверкой

Сверено с документацией [MAX для разработчиков](https://dev.max.ru/docs/webapps/introduction) 16.09.2026.

- [ ] В `main` влиты ветки `feature/two-oge-rules`, `feature/compare-programs`, `feature/pilot-region` и `feature/share-link-prefetch` — сценарий ниже рассчитан на них.
- [ ] Бота выдали организаторы, у команды есть только токен. Никнейм — из ответа `GET https://platform-api2.max.ru/me`, сервер определяет его сам. В презентации — ссылка `https://max.ru/<никнейм>`. Название, ник и логотип на онлайн-этапе менять нельзя.
- [ ] Сервис развёрнут по HTTPS (`docker compose --profile https up --build -d`), `https://<DOMAIN>/api/health` отвечает `{"status":"ok","bot":"running",…}`.
- [ ] Ссылка на мини-приложение (`https://158-160-18-41.sslip.io/`) отправлена организаторам через форму, и они привязали его к боту: в чате с ботом появилась кнопка запуска мини-приложения. Административного доступа к боту у команды нет — если что-то нужно поменять в настройках, пишем на support@hackathon-max.vk.company.
- [ ] Два аккаунта MAX: «родитель» и «подросток». Ни один из них раньше не открывал бота — чтобы проверить первый запуск.

## Особенности MAX Bridge, которые влияют на проверку

| Метод | Где используется | Что проверить |
|---|---|---|
| `initData` | каждый запрос к API | без подписи API отвечает 401 — значит, мини-приложение открыто не из MAX |
| `shareMaxContent({ text, link })` | «Отправить план подростку» | экран выбора чата открывается **сразу** после нажатия: MAX Bridge пропускает вызов только в ответ на клик |
| `openMaxLink` | запасной вариант шеринга | срабатывает, если экран шеринга не открылся |
| `openLink` | ссылки на источники | ссылка открывается во внешнем браузере, тоже только по нажатию |
| `BackButton` | карточка колледжа, сравнение, изменение ответов | системная кнопка «Назад» появляется и возвращает на предыдущий экран |
| `HapticFeedback` | отметки, избранное | на телефоне есть отклик; в веб- и десктоп-версии методы не поддерживаются — ошибок быть не должно |
| Диплинк `https://max.ru/<бот>?startapp=plan_…` | план по ссылке | payload — до 512 символов, только `A–Z a–z 0–9 _ -` |

Диплинк `:share` не поддерживается в десктоп-клиенте MAX — если шеринг не открылся на десктопе, это ограничение платформы, а не ошибка. Проверьте, что ссылка скопировалась и появилось сообщение об этом.
