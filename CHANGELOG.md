# Версии

Каждая версия отмечена тегом в git. К любой версии можно вернуться на сервере одной командой:

```bash
./scripts/deploy.sh --rollback v0.1.0
```

Как выпускать версии и откатываться — в [docs/releases.md](docs/releases.md).

Доработки бота по итогам разбора недостатков (ветка `feature/bot-fixes`), каждая — отдельным коммитом, чтобы при проблеме откатить одну:

- Пример напоминания по кнопке «⏰ Пример напоминания» — после опроса и при включении напоминаний; `/test_reminder` в меню команд. Пример выглядит и работает как настоящее напоминание.
- Кнопки под напоминанием не стирают его: «Подробнее» присылает карточку новым сообщением, «✅ Сделано» меняет только кнопку.
- После опроса — кнопки «Все даты», «Колледжи», «Отправить план подростку», «Пример напоминания».
- Сравнение путей «10–11 класс или колледж» в чате: `/paths`, кнопка в меню и в приветствии.
- План семьи у подростка: после подписки `/start`, меню и `/plan` показывают план, которым поделились, все даты и карточки со статусом.
- Отправка плана: ссылки на отдельных строках, отзыв ссылки прямо в чате.
- Свободный текст: частые темы («когда ОГЭ», «колледжи», «средний балл», «10 класс или колледж», «напоминания») ведут в нужный раздел; на непонятное — короткая подсказка и меню. Без ИИ, текст не сохраняется.
- Колледжи в чате: программы из разных колледжей, сгруппированы по колледжу, короткие пронумерованные кнопки; в опросе честно о городах справочника.
- «Другой регион»: федеральные сроки и напоминания для семей не из пилотного региона, вопрос о городе пропускается. Пилотный регион в опросе первым, демо — в конце.
- 8 класс: шаги подготовки на текущий год (профориентация, предметы ОГЭ, отметки по предметам, которые заканчиваются в 8 классе, напоминание обновить класс) и даты 9 класса, когда их опубликуют.
- Сроки по-русски: «через 3 дня», дальние даты — в месяцах.
- Сообщения со ссылками и командами уходят без оформления — ссылки гарантированно нажимаются.
- Миграции 003 и 004 только добавляют столбцы. При откате на v0.2.0 те, кто выбрал «Другой регион», пройдут опрос заново, остальные данные сохраняются.

Подготовка к сдаче (ветка `feature/submission-ready`, поверх `feature/bot-fixes`):

- Версия в `/api/health` (`version`: тег и коммит) и режим получения событий (`botMode`).
- Защита бота от флуда: `BOT_RATE_LIMIT_PER_MINUTE` (по умолчанию 40 в минуту на пользователя), `0` — выключить.
- Ссылки для школ: `/link <код>` для команды проекта, `?startapp=src_<код>` и `?start=src_<код>`; в `/stats` — сколько семей пришло по каждому коду и сколько собрали план.
- Webhook для бота (`BOT_MODE=webhook`) — рекомендованный MAX способ для production. По умолчанию остаётся Long Polling; если MAX не примет адрес, бот сам вернётся на Long Polling.
- `npm run api:check` — проверки `DATA-API.yaml` как у платформы оценки, они же в GitHub Actions. OpenAPI: `operationId`, явные открытые методы, ответ 429, `/api/meta` и `/bot/webhook`; валидатор Redocly — без ошибок.
- README: «Параметры окружения», «Что нельзя воспроизвести внутри Docker», «Возможности MAX сверх минимальных требований».

Уже в `main` (PR #15–#17):

- Колледжи в чате: `/colleges` и «🏫 Колледжи по интересам» в меню — программы по интересам и городу, карточка с источником, избранное.
- Безопасное обновление сервера с автооткатом: `scripts/deploy.sh`.
- Оформление сообщений бота: заголовки и подписи разделов жирным; выключается `BOT_RICH_TEXT=false`.
